# F4L: historial de integración del jurado

- El alta inicial conserva los seis lugares existentes (representación x calidad).
- La presentación (excusación/recusación) no modifica la integración vigente.
- Registrar resolución rectoral es condición para dar de baja el integrante.
- Si hay suplente vigente cuando cesa el titular, la misma transacción primero marca baja del titular y luego promueve al suplente de esa representación. La plaza suplente queda vacante.
- Si no hay suplente vigente o se da de baja a un suplente, la plaza queda vacante hasta una nueva designación formal.
- Una nueva designación para una plaza con antecedentes requiere resolución rectoral; el alta inicial de una plaza nunca cubierta usa el formulario de siempre.
- Integrantes históricos permanecen en la base, no se eliminan, y no integran la lista actual ni los modelos documentales.
- Una corrección de datos personales no representa un cambio de plaza.
- Solo usuarios con view_concurso y change_concurso registran estas actuaciones. La consulta requiere view_concurso.
- La fecha de resolución se registra, sin recalcular automáticamente vigencias históricas ni fabricar efectos retroactivos. El documento oficial sigue siendo la fuente de verdad.
