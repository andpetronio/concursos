| ID | Estado | Entrega | Condición de paso |
|---|---|---|---|
| SDD-001 | Aceptada por el usuario (reconfirmado 23/10/2026) | Fundaciones, autenticación, UI común, 30 min inactividad | Autorización expresa de SDD-004 recibida |

| SDD-900 | Futuro / sin ejecutar | Integración CoPla (consulta DNI e impacto designación) | API y reglas acordadas en ambos proyectos |

Regla: **una fase por turno**, sin anticipar implementación por aprovechar que «es fácil». Al final de cada fase, el operador revisa la entrega y autoriza la siguiente.

Cada spec define objetivo, alcance, criterios de aceptación y no objetivos. Las fases futuras son contexto, no órdenes de ejecución.
